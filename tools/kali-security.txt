# ZyraxonOS — Kali Linux security toolset (built in)
#
# The full Kali security collection, installed into the image. Nothing
# else is needed: this list plus Chromium is the whole tool payload.
#
# Kali publishes its tools as metapackages. Installing these brings in
# every security tool Kali ships, grouped the way Kali groups them.
#
# Format: metapackage | what it gives you
kali-tools-information-gathering | DNS, OSINT, scanning and enumeration
kali-tools-vulnerability          | vulnerability scanners and fuzzers
kali-tools-web                    | web application attack tools
kali-tools-database               | database assessment
kali-tools-passwords              | password cracking and wordlists
kali-tools-wireless               | Wi-Fi and Bluetooth attacks
kali-tools-reverse-engineering    | RE, disassembly, decompilation
kali-tools-exploitation           | exploitation frameworks
kali-tools-social-engineering     | phishing and SE toolkits
kali-tools-sniffing-spoofing      | sniffing, spoofing, MITM
kali-tools-post-exploitation      | post-exploitation and pivoting
kali-tools-forensics             | forensics and data recovery
kali-tools-reporting             | reporting helpers
kali-tools-crypto-stego          | cryptography and steganography
kali-tools-defensive             | defensive and hardening tools
kali-linux-headless              | the Kali base + the above, headless
